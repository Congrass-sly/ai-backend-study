一、函数参数进阶（面试高频）
1. 函数参数类型及传参规则（必背）
（1）四大基础参数
- 位置参数（必选参数）：优先级最低、最死板，必须严格按定义顺序、对应类型传参，不可省略、不可乱序。
- 关键字参数：调用时指定 参数名=值，无需按顺序，匹配参数名即可；注意：关键字参数必须在位置参数之后。
- 默认参数：函数定义时给参数赋初始值，调用时不传该参数则使用默认值，传参则覆盖默认值；易错点：默认参数不可用可变对象（list、dict、set），否则会共享残留数据。
- 不定长参数（高频）：
        
  - *args：接收任意多个位置参数，自动打包为元组；
  - **kwargs：接收任意多个关键字参数，自动打包为字典；
  - 作用：实现万能传参，适配未知参数个数的场景。
（2）参数定义顺序（必背）
位置参数 → 默认参数 → *args → **kwargs（顺序错误直接报错，面试常考判断题）。
（3）Python 3.8+ 新增参数分隔符（高频考点）
用 / 和 *限制传参方式，函数定义格式及规则：
def f(a, b, /, c, d, *, e, f):
    pass
- / 左边（a、b）：只能位置传参，不能用关键字传参（如 a=1 错误）；
- / 和 * 中间（c、d）：位置、关键字传参均可；
- * 右边（e、f）：只能关键字传参，不能用位置传参（如直接传 5、6 错误）。
面试答题话术：/ 用于区分“必须位置传参”和“可混合传参”的参数，* 用于区分“可混合传参”和“必须关键字传参”的参数，核心是规范传参方式，避免歧义。
2. 函数传参的内存逻辑（高频、易错）
核心：Python 传参本质是「地址引用」，区别在于可变对象和不可变对象的内存是否可共享。
（1）不可变对象（int、float、str、tuple）
- 传参时，函数内外共享同一个地址，但不可变对象无法原地修改；
- 函数内对不可变对象重新赋值，会开辟新的临时内存地址，仅在函数内有效；
- 函数结束后，临时地址释放，外部原对象的地址和值均不改变（面试必答）。
# 示例（面试常考）
def func(n):
    n = 999  # 开辟临时地址，不影响外部
a = 10
func(a)
print(a)  # 输出 10，未改变
（2）可变对象（list、dict、set）
- 传参时，函数内外共享同一个内存地址；
- 函数内「原地修改对象内容」（如 append、pop、修改字典值），会直接影响外部原对象；
- 易错点：若函数内对可变对象重新赋值（如 li = []），会断开与原地址的引用，不影响外部对象。
# 示例（面试常考）
def func(li):
    li.append(999)  # 原地修改，影响外部
lst = [1,2]
func(lst)
print(lst)  # 输出 [1,2,999]
面试答题话术：不可变对象传参“赋值即新建”，不影响外部；可变对象传参“共享地址，原地修改影响外部，重新赋值不影响”。
二、lambda 匿名函数（面试高频）
1. 核心定义（必背）
lambda 是「单行、匿名、简易临时函数」，语法：lambda 参数: 表达式，自动返回表达式结果，无需写 return。
2. lambda 与普通 def 函数的区别（面试必答）
对比维度
        lambda 函数                                 def 普通函数
函数名   无（匿名）                                 有，可命名、可复用

代码行数 只能1行表达式，无代码块                     任意多行，支持完整代码块

语句支持 不支持 for、while、if 语句、print 等        支持所有语句（循环、分支、异常等）

返回值   自动返回表达式结果                          需用 return 手动返回

复用性   临时、一次性使用，不适合复用                 可反复多处调用，适合复杂逻辑


3. lambda 适用场景（面试高频）
- 作为高阶函数参数：配合 sorted()、map()、filter()，传递简单排序/映射/筛选规则（最常用）；
- 简单临时逻辑：逻辑仅1行，无需单独定义 def 函数；
- 字典分支映射：用字典存储简单运算/逻辑，替代多分支 if 语句；
- 回调函数：简单的临时回调逻辑封装。
# 面试高频示例
# 1. sorted 排序（按元组第2个元素）
lst = [(2,3), (1,9), (5,1)]
sorted(lst, key=lambda x: x[1])

# 2. map 映射（每个元素乘2）
list(map(lambda x: x*2, [1,2,3]))

# 3. 字典分支映射
calc = {"add": lambda x,y: x+y, "sub": lambda x,y: x-y}
4. lambda 使用禁忌（易错点，面试常考）
- 不可写多行代码、循环、if 语句（可写三元表达式，如 lambda x: x*2 if x%2==0 else x）；
- 不可封装复杂逻辑，否则可读性极差，需改用 def 函数；
- 不推荐赋值给变量长期使用（违反匿名设计初衷）；
- 不支持函数注释，复杂逻辑无法说明用途。
三、sorted() 函数 key 参数（面试高频）
1. key 参数核心作用（必背）
key 接收一个函数（常用 lambda），用于指定「排序依据」：sorted 会遍历可迭代对象的每个元素，将元素传入 key 函数，用函数返回的“替身值”进行排序，最终返回的还是原元素。
2. 高频示例（面试必写）
- 按元组指定位置排序：sorted(lst, key=lambda x: x[0])（按第1个元素）；
- 按绝对值排序：sorted(lst, key=lambda x: abs(x))；
- 字典列表按指定 key 排序：sorted(users, key=lambda x: x["age"])；
- 倒序排序：添加 reverse=True，如 sorted(lst, key=lambda x: x[1], reverse=True)。
四、面试高频问答汇总（直接背诵）
1. 问：Python 中函数参数的传参本质是什么？可变对象和不可变对象传参有什么区别？
答：传参本质是地址引用。不可变对象（int、str 等）传参时，函数内重新赋值会开辟临时地址，不影响外部；可变对象（list、dict 等）传参时，共享地址，原地修改会影响外部，重新赋值则不会。
2. 问：lambda 函数和 def 函数的区别是什么？什么时候用 lambda？
答：lambda 是单行匿名简易函数，只能写表达式、自动返回结果，适合临时、简单逻辑（如 sorted  key 参数）；def 是完整命名函数，支持多行代码、复杂逻辑，适合复用和复杂业务。
3. 问：sorted() 函数的 key 参数作用是什么？举一个例子。
答：key 用于指定排序依据，接收一个函数，用函数处理每个元素后的结果作为排序标准，最终返回原元素。示例：按列表 [(2,3), (1,9)] 的第2个元素排序，sorted(lst, key=lambda x: x[1])。
4. 问：Python 中 / 和 * 在函数参数中是什么作用？
答：是参数分隔符，用于限制传参方式。/ 左边的参数只能位置传参，* 右边的参数只能关键字传参，中间的参数可混合传参。
5. 问：不定长参数 *args 和 **kwargs 的区别是什么？
答：*args 接收任意多个位置参数，打包为元组；**kwargs 接收任意多个关键字参数，打包为字典，两者结合可实现万能传参。
